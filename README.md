# 👋 Sobre mí  

🚀 **De Emprendedor a Analista de Datos: Convirtiendo la Experiencia en Datos Accionables.**

Mi viaje profesional me enseñó que para construir un negocio exitoso se necesitan dos cosas: **pasión por el proyecto** y **datos claros**.  
Como emprendedor en gestión, marketing y desarrollo de proyectos, viví el reto de la información fragmentada.

Esa fue mi motivación para especializarme como **Analista de Datos en SoyHenry**.

Hoy, mi experiencia en la ejecución integral de negocios se une a mis nuevas habilidades técnicas en:

- **SQL Server**  
- **Python**  
- **Power BI**  
- **Google Sheets**

Busco un equipo donde pueda aplicar esta **doble visión (negocio + data)** para transformar procesos, mejorar la eficiencia operativa y generar impacto medible.
